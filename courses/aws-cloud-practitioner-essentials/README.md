# AWS Cloud Practitioner Essentials — AWS Skill Builder

## About This Course

First real step into cloud, official AWS course through Skill Builder. 13 modules, no labs, just going through the actual foundations before jumping into hands on stuff later. did this before FreeCodeCamp's version so i'd already have the vocabulary down instead of hearing terms like EC2 or IAM for the first time in a 14 hour video.

Coming off SOC training, alot of the security module especially felt like it lined up with stuff i already sort of knew, just from the AWS side instead of general networking side.

**Status:** Completed

---

## What It Covered

13 modules total:

- Intro to the cloud, then compute basics and a deeper look at specific compute services (EC2 mainly)
- Going global — how AWS infrastructure is spread across regions/availability zones
- Networking, storage, and databases as their own dedicated modules
- AI/ML and data analytics — lighter touch, more "here's what exists" then hands on
- Security — probably the module i paid most attention to given the SOC background
- Monitoring, compliance and governance
- Pricing and support, migrating to AWS, and Well-Architected Solutions to close it out

---

## What Actually Stuck

Security module was the one that connected the most dots for me already having SOC training. Shared responsibility model specifically — AWS secures the cloud itself, you secure what you put in it — is a simple idea but it reframed a bunch of stuff i already knew about defense in depth, just applied to cloud infra instead of a regular network.

Networking module took a bit more effort. VPCs, subnets, all that maps onto stuff from the cisco courses but the terminology's different enough that i had to slow down and actually match it up mentally instead of assuming it was 1:1 the same.

Pricing and support module i almost skipped mentally going in, figured it'd be boring, but it's actually genuinely useful — understanding how AWS billing works is the kind of thing that actually matters day to day once you're using this for real, not just conceptually.
